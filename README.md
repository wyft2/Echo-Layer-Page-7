# 回声层：第七页

> 2014年9月7日凌晨，一台名为 **JIANGTING-07** 的旧电脑重新启动。
> 论坛已经关闭，但还有一些回复在继续出现。

一个原创的中文网络怪谈解谜游戏。你在一台2014年的旧电脑上，调查一个已经停止运营的社区论坛，比较两个相差13分钟的论坛副本，并决定要不要回答那个一直在等待回答的问题。

- 类型：点击解谜 / 变格推理 / 模拟旧电脑 / 双结局
- 时长：约 20–40 分钟
- 线索：14 条（自动归档）
- 结局：2 个
- 技术：纯 HTML / CSS / JavaScript，无外部依赖、无网络请求；进度保存在浏览器 localStorage
- 建议：手机竖屏或桌面浏览器；佩戴耳机；声音默认关闭，可在状态栏打开

---

## 运行

在这个目录里打开终端：

```bash
python3 -m http.server 8899
```

然后浏览器访问：

```
http://127.0.0.1:8899/
```

也可以直接双击 `index.html`（file:// 打开也能玩，但部分浏览器可能不保存进度，建议用本地服务器）。

## 操作

- 桌面图标：单击打开
- 浏览器：标签页切换表面论坛 / 深层备份；左上角后退、刷新；地址栏可以手动输入站内路径
- 状态栏：`线索簿` 查看已归档线索和下一步提示；`声音` 打开环境音
- 存档：自动保存；标题页可以继续上次调查
- 窗口：右上角 `×` 关闭；关闭浏览器后再打开，深层备份标签页会保留

## 素材说明

当前版本采用“程序生成 + AI 生成”的混合素材，均为虚构档案照片，不对应任何真实人物或事件：

- **AI 写实照片**：`photo_group.jpg`（夜班合影，六个人的背影）、`avatar_wind.jpg`（晚风）、`avatar_nan.jpg`（南岸）、`avatar_zhou.jpg`（老周）。
- **程序生成素材**：`avatar_man.jpg`（小满）、`avatar_mei.jpg`（阿梅）、`avatar_chen.jpg`（小陈），以及 `photo_station.jpg`、`photo_street.jpg`、`photo_corridor.jpg`、`wallpaper.jpg`。

小满、阿梅、小陈的头像和几张场景图还没来得及替换成写实照片，后续可以按同名文件直接覆盖，页面无需改动：

- `photo_group.jpg` 夜班合照（建议 3:2）
- `photo_station.jpg` 服务站门口 / `photo_street.jpg` 老街 / `photo_corridor.jpg` 二楼走廊（建议 3:2）
- `avatar_*.jpg` 人物头像（建议 1:1）
- `wallpaper.jpg` 桌面壁纸

原程序生成版本保存在 `tools/procedural-backup/`，需要回滚时复制回 `assets/img/` 即可。
